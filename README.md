# Afinador de Violão e Cordas

Afinador e metrônomo para iOS e Android, feito em Flutter. Um app Bancada.

- [afinador_flutter/](afinador_flutter/) — o app. Instruções em [LEIA-ME.md](afinador_flutter/LEIA-ME.md).
- [docs/](docs/) — site do app (suporte e política de privacidade), publicado pelo GitHub Pages.
- [tarraxa.html](tarraxa.html) — protótipo web de referência, de comportamento e visual.

O microfone é usado só para analisar o som no aparelho. Nada é gravado nem enviado.
